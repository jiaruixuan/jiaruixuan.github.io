# Ruixuan Jia Academic Homepage

This is a static academic homepage designed for GitHub Pages. It does not require a build step.

## Local Preview

Open `index.html` directly in a browser.

## Deploy to GitHub Pages

Recommended repository name:

```text
jiaruixuan.github.io
```

Deployment options:

1. Copy everything inside this `website/` directory into the root of `jiaruixuan.github.io`.
2. Push to the `main` branch.
3. In GitHub, open `Settings -> Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Select `main` and `/root`.

The page will be available at:

```text
https://jiaruixuan.github.io
```

## Update Content

- Edit text in `index.html`.
- Replace `assets/Ruixuan_Jia_CV.pdf` when the CV changes.
- Keep filenames stable to avoid broken links.
